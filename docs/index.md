## Presentació del projecte

Projecte ASIX és una web de documentació creada per organitzar diferents continguts relacionats amb sistemes informàtics, xarxes, serveis, seguretat i desenvolupament web.

La informació d'aquesta web s'anirà ampliant i modificant al llarg del curs.

## Objectius

Els principals objectius del projecte són:

- Organitzar els apunts del curs.
- Documentar les pràctiques realitzades.
- Aprendre a treballar amb Markdown.
- Utilitzar MkDocs per generar una web estàtica.
- Publicar la documentació mitjançant GitHub Pages.

## Continguts

En aquesta secció es podran incloure continguts relacionats amb:

- Sistemes operatius.
- Xarxes.
- Seguretat informàtica.
- Bases de dades.
- Serveis de xarxa.
- Implantació d'aplicacions web.
- Administració de sistemes.
